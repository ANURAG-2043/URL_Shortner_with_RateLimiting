# 🔗 URL Shortener with Rate Limiting (Spring Boot + Redis)

## 🚀 Project Overview

A scalable and production-ready **URL Shortener Service** built using **Java, Spring Boot, Redis, and JPA**, designed to convert long URLs into short, shareable links with **high performance, caching, and rate limiting**.

This system mimics real-world services like Bitly by implementing **efficient encoding, caching strategies, and request throttling**.

---

## 🎯 Key Features

* 🔹 URL Shortening using **Base62 Encoding**
* 🔹 High-speed redirection with **Redis caching**
* 🔹 **Rate Limiting** using Redis (prevents abuse)
* 🔹 RESTful APIs for URL creation and retrieval
* 🔹 Click tracking and analytics support
* 🔹 Full-stack integration with HTML/CSS/JS frontend
* 🔹 Supports both **H2 (dev)** and **MySQL (prod)**

---

## 📊 Resume Impact (Use This 💯)

## 🧠 Core Concepts Used

### 1. Base62 Encoding

* Converts numeric IDs → short strings
* Characters used: `[a-zA-Z0-9]`
* Ensures **unique, compact, URL-safe identifiers**

---

### 2. Caching (Redis)

* Cache-aside pattern
* Flow:

  * Check Redis → If miss → Fetch from DB → Store in Redis
* Reduces DB calls drastically

---

### 3. Rate Limiting

* Implemented using Redis atomic operations
* Prevents:

  * DDoS attacks
  * API abuse
* Strategy: **Fixed Window / Sliding Window (extendable)**

---

### 4. REST API Design

* `POST /shorten` → Create short URL
* `GET /{shortCode}` → Redirect
* `GET /stats/{shortCode}` → Analytics

---

### 5. Database Design

**Table: URL_MAPPING**

| Column       | Description                |
| ------------ | -------------------------- |
| id           | Auto-increment primary key |
| original_url | Long URL                   |
| short_code   | Encoded string             |
| click_count  | Number of accesses         |

## 🔄 System Flow

### 🔹 URL Shortening Flow

```
User → UI → POST /shorten
        ↓
Controller
        ↓
Service Layer
        ↓
Generate ID (DB)
        ↓
Base62 Encode
        ↓
Save Mapping
        ↓
Return Short URL
```

---

### 🔹 Redirect Flow

```
User hits short URL (/abc)
        ↓
Controller
        ↓
Check Redis Cache
   ↓           ↓
Hit           Miss
↓              ↓
Redirect     Fetch from DB
             ↓
         Store in Redis
             ↓
          Redirect
```

---

### 🔹 Rate Limiting Flow

```
Request → Filter
        ↓
Check Redis Counter
        ↓
Allowed? → Yes → Proceed
         → No → 429 Too Many Requests
```
